## Что есть сейчас (прототипы)

Два рабочих прототипа, сделанных как артефакты Claude, лежат в `prototypes/`:

- `prototypes/chto-posmotret.html` — **«Что посмотреть»** (фильмы и сериалы). Тёмная тема, акцент **оранжевый** (#ffb547 → #ff6b5b).
- `prototypes/chto-pochitat.html` — **«Что почитать»** (книги и аудиокниги). Тёмная тема, акцент **изумрудный** (#5ee0b0 → #38b6d6).

В прототипах ИИ вызывается через `claude.use("sample")`, данные хранятся через `claude.use("db")`, голос — `claude.use("dictation")`. Это API артефактов Claude, **вне Claude они не работают** — их нужно заменить (см. архитектуру ниже). Вёрстку, тексты, промпты и логику бери из прототипов как образец.

Мои текущие списки и описание вкуса: `data/films.json`, `data/books.json` — перенести в мой аккаунт в новом приложении.

PDF-презентация обоих приложений (стиль, тексты, иллюстрации): `design/guide.pdf` и исходник `design/guide.html`.

## Функции (что должно остаться)

### Общее для обоих
- Две вкладки: **«Подобрать»** и **«Мой список»**.
- Подбор: выбор параметров чипами → ИИ возвращает **3 варианта** с пояснением «почему именно вам».
- Кнопка **🎲 «Удиви меня»** — 1 неочевидный вариант.
- **«Не то — ещё варианты»** — новые варианты без повторов.
- Отметки на каждой карточке; отмеченное больше никогда не предлагается.
- **«Быстро добавить»** — свободный текст/диктовка («посоветовали «Шерлок»», «начал читать…») → ИИ сам определяет название и раздел.
- **«Мой вкус»** — текст предпочтений, всегда передаётся в промпт, редактируемый.
- Все разделы «Мой список» **сворачиваются** (details): «Смотрю/Читаю сейчас», «Посмотреть позже / Хочу прочитать», «Понравилось», «Не зашло», «Видел / Прочитал», «Мой вкус».
- Иконки — единый контурный SVG-стиль (никаких эмодзи в интерфейсе).

### «Что посмотреть»
- Чипы: Фильм / Сериал / Всё равно; настроение: Напряжённо, Неожиданная концовка, Посмеяться, Лёгкое, Криминал, Залипнуть; поле «Похоже на…».
- Отметки: Позже, Понравилось, Видел, Не моё (для сериалов вместо «Видел» — «Смотрю»).
- «Смотрю сейчас»: сезон и серия (− / + серия / Новый сезон), «Досмотрел» → сразу подбор похожего.
- Ссылки: «Трейлер» (поиск YouTube по русскому названию + «трейлер на русском»), «Кинопоиск» (поиск по русскому названию без года).
- **«Новинки недели»** раздел вверху — свежие релизы (поиск в интернете), обновлять по пятницам.

### «Что почитать»
- Чипы: История / Полезное / Всё равно; Как: Слушать / Читать / Неважно; настроение: Захватывающий сюжет, Неожиданная развязка, ИИ и технологии, Прокачать себя, Психология, Реальные истории, Короткое; «Похоже на…».
- Отметки (5 кнопок): Позже, Читаю, Читал, Зашло, Не моё.
- «Читаю сейчас»: прогресс в % (−10% / +10%) с полоской, «Дочитал» → подбор похожего.
- В режиме «Слушать» — книги с хорошей аудиоверсией (чтец, длительность).
- Ссылки: «Литрес», «Обзор» (YouTube).
- Принцип промпта: простой язык, затягивает с первых страниц, для человека, который не любит читать.

### Уроки из прототипа (важно)
- ИИ иногда повторяет один вариант дважды → дедупликация по нормализованному названию.
- Ответ одним JSON-массивом ломался из-за кавычек → просить **JSON Lines** (один объект на строку, только «ёлочки» внутри), парсить построчно, битые строки пропускать.
- **Стриминг**: показывать карточки по мере появления, остановить запрос, когда набралось 3 новых.
- Просить с запасом (count+2), фильтровать уже отмеченное и показанное; если новых 0 — один автоматический повтор, затем понятное сообщение.
- Не кэшировать ответы подбора.

## Решения по новой архитектуре (согласовано)

- **Два отдельных приложения** (две ссылки, две иконки), общий дизайн-код.
- **Веб-приложение (PWA)** на **GitHub Pages** (мой GitHub: `antoha17`), устанавливается ярлыком на iPhone/Android/компьютер. Короткие адреса, напр. `antoha17.github.io/kino` и `.../knigi`.
- Данные — **Supabase** (бесплатный тариф): вход по почте (код/ссылка) или Google, у каждого свой список, синхронизация телефон ↔ компьютер, ничего не теряется при очистке браузера. Оба приложения — в одном проекте Supabase. Row Level Security: каждый видит только свои данные.
- **ИИ — через мой ключ, на сервере**: Supabase Edge Function хранит ключ в секретах; приложение ходит в функцию, а не напрямую к провайдеру. Ключ никогда не попадает в код клиента.
  - Функция работает на зарубежном сервере → у друзей и у меня работает из России без VPN.
  - **Белый список почт** (только приглашённые могут пользоваться ИИ), **дневной лимит** на человека (напр. 20 подборов), страница статистики для меня.
  - Возможность для друга вставить свой ключ в настройках (опционально, без лимитов).
- **Выбор модели в настройках/на сервере**: OpenAI (ключ уже есть) — `gpt-6.2-sol` (аналог Claude Sonnet, $2/$10 за 1M токенов) или дешевле `gpt-6.1-terra` ($0.50/$2.50); Claude Sonnet/Haiku — если появится ключ Anthropic (из России оплата затруднена). Добавить кнопку «Проверить модель» (пробный запрос).
- «Новинки недели» — один поиск в интернете раз в неделю **на всех** (cron в Supabase), результат кладётся в общую таблицу.
- Подсказка при первом запуске: как добавить на экран (iPhone / Android / компьютер), короткая анкета вкуса для новых пользователей.

## Ограничения и факты

- Я в России: зарубежные оплаты неудобны; OpenAI и Anthropic API официально Россию не поддерживают — поэтому вызовы ИИ только с сервера.
- Supabase Free: 2 активных проекта, 500 МБ БД, проект **ставится на паузу после 7 дней без активности** → нужен периодический «пинг» (GitHub Actions cron или аналог).
- Base44 отвергнут: свой ключ только на платном тарифе Builder.
- Ориентир расходов на ИИ: ~$0.01 за подбор на sol, ~$6/мес на 6 человек (sol) или ~$1.7 (terra). Поставить месячный лимит расходов в кабинете OpenAI.
