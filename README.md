# Что почитать

Личный помощник: подбирает книги и аудиокниги под ваш вкус и настроение с помощью ИИ и ведёт ваш список.

- Адрес: https://antoha17.github.io/knigi/
- Второе приложение: [Что посмотреть](https://antoha17.github.io/kino/), репозиторий `antoha17/kino`
- Подробности про устройство и планы в `CLAUDE.md`
- Общая база данных обоих приложений описана в репозитории `antoha17/kino`, папка `supabase/`

## Как устроено

| Файл | Что это |
|---|---|
| `index.html` | вёрстка и оформление |
| `app.js` | логика: подбор, список, отметки, подсказка по установке |
| `config.js` | адрес и публичный ключ Supabase (секретов здесь нет и не будет) |
| `admin.js` | раздел «Статистика» в «Моём списке» (только владелец): места, ссылки-приглашения, люди (одинаковый в обоих приложениях) |
| `sync.js` | вход по почте и паролю и синхронизация списка с Supabase (одинаковый в обоих приложениях) |
| `vendor/supabase.js` | библиотека Supabase (MIT), лежит в приложении, чтобы не зависеть от сторонних серверов |
| `sw.js` | мгновенное открытие, работа без интернета и автообновление. **При любом изменении файлов увеличивать номер версии `CACHE` в начале файла**, иначе телефоны не узнают о новой версии |
| `fonts/` | шрифты Manrope и Unbounded (лицензия OFL), лежат в приложении |
| `manifest.webmanifest`, `icons/` | установка ярлыком на экран |

## Журнал сессий

### 18.11.2026. Шаг 1, каркас приложения
- Интерфейс перенесён из прототипа: вкладки «Подобрать» и «Мой список», чипы, карточки, отметки, сворачиваемые разделы, «Мой вкус», «Быстро добавить».
- Приложение ставится на экран телефона и компьютера: манифест, иконки, service worker (открывается и без интернета, при каждом открытии берёт свежую версию).
- При первом открытии: подсказка, как установить (iPhone / Android / компьютер).
- Список пока хранится только в этом браузере. ИИ-подбор ещё не подключён: появится после настройки Supabase (шаги 2–3).

### 18.11.2026. Убрана кнопка микрофона
- На iPhone приложение зависало после нажатия микрофона. Кнопку убрали: диктовать можно через микрофон на клавиатуре телефона, подсказка об этом осталась.

### 18.11.2026. Надёжное автообновление
- Телефон держал старую версию из кэша. Теперь приложение при каждом открытии и возвращении проверяет обновление и само перезагружается, когда оно вышло.

### 18.11.2026. Все разделы списка видны всегда
- Разделы «Мой список» показываются даже пустыми, с подсказкой, что в них появится.

### 18.11.2026. Подсказки без жаргона
- В пояснениях «зашло / не зашло» заменено на «понравилось / не понравилось». Названия кнопок и разделов не менялись.

### 18.11.2026. Без длинных тире
- В текстах интерфейса убраны длинные тире: фразы перестроены через точку, запятую или двоеточие. Короткое тире оставлено только там, где его требуют правила (диапазон «3–4»).

### 18.11.2026. Шаг 2, вход и синхронизация
- Создан проект Supabase `kino-knigi` (Франкфурт), оба приложения подключены к нему.
- Вход по почте: приходит код из письма, его вводят в приложении. Ссылка из письма не используется: на iPhone она открылась бы в Safari, а не в установленном приложении.
- После входа список и «Мой вкус» хранятся на сервере и одинаковы на всех устройствах. Без входа всё работает как раньше, только на этом устройстве.
- Если до входа на устройстве уже были записи, при первом входе они добавляются к списку на сервере.
- Без интернета изменения копятся и отправляются, когда связь появится.
- Таблицы `items` и `tastes` с защитой «каждый видит только своё» (RLS).

### 18.11.2026. Вход по почте и паролю вместо кода
- Supabase без собственного почтового сервера не даёт менять текст писем, поэтому код в письмо не положить. Перешли на вход по почте и паролю: регистрация, вход, «Забыли пароль?» (письмо со ссылкой, новый пароль задаётся на странице приложения).
- Подтверждение почты при регистрации выключено в настройках Supabase, чтобы не зависеть от писем.

### 18.11.2026. Экран входа при открытии
- Пока человек не вошёл, вместо вкладок сразу показывается экран входа: почта, пароль, «Создать аккаунт», «Забыли пароль?». После входа открывается «Подобрать».
- Убрана надпись «Всё сохранено». Под почтой появляется предупреждение, только если сохранить не удалось.

### 18.11.2026. Быстрое открытие
- Было: около 3 секунд чёрного экрана. Приложение при каждом открытии ждало ответа GitHub, а шрифты грузились с серверов Google.
- Стало: всё открывается сразу из памяти телефона, даже без интернета. Новая версия скачивается в фоне, приложение один раз тихо перезагружается.
- Шрифты лежат в самом приложении.
- Экран входа или список показываются сразу, не дожидаясь ответа сервера.

### 18.11.2026. Плавное открытие
- Новая версия больше не перезагружает экран на глазах: она скачивается в фоне и включается, когда приложение свёрнуто.
- Шрифты показываются сразу нужные, без подмены (заголовок не прыгает).
- Содержимое мягко проявляется при открытии (0,2 с).

### 18.11.2026. Понятная кнопка «Удиви меня»
- Рядом с кубиком появилась подпись «Удиви». На узких экранах кнопки не переносятся на две строки (на самых узких главная кнопка называется просто «Подобрать»).

### 18.11.2026. Решение: модель выбирает только владелец
- У пользователей не будет настроек модели и своего ключа. Модель для всех выбирает владелец на странице «Статистика», и она сразу действует у всех.

### 18.11.2026. Места и ссылка-приглашение, страница «Статистика»
- Регистрация только по секретной ссылке-приглашению и только пока есть свободные места (на старте 8, владелец место не занимает). Проверку делает сервер Supabase при создании аккаунта (хук Before User Created), обойти через приложение нельзя.
- Без приглашения можно только войти в существующий аккаунт.
- Страница «Статистика» (ссылка внизу экрана, видна только владельцу): число мест −/+, ссылки-приглашения для обоих приложений («Отправить» / «Скопировать», «Новая ссылка»), список людей: когда зарегистрировался, последний заход, сколько записей в списках (без названий), «Отключить» / «Включить» / «Удалить».
- Отключённый человек видит «Доступ отключён» и не может читать и менять список.
- SQL: `supabase/02_access.sql` (в репозитории kino).
- Проверено на настоящем Supabase: регистрация с неверным кодом отклоняется, приложение показывает «Регистрация только по приглашению».

### 18.11.2026. «Статистика» — раскрывающийся раздел в «Моём списке»
- Убрана ссылка внизу экрана. «Статистика» теперь последний раздел в «Моём списке», раскрывается как остальные. Виден только владельцу и появляется сразу, без задержки.
- Подпись у людей: «записей: кино 6 · книги 5», то есть все записи во всех разделах списка.

### 18.11.2026. Заголовки разделов без пояснений
- Убраны подписи «это я учитываю всегда» у «Мой вкус» и «видите только вы» у «Статистика».

### 18.11.2026. «Поблагодарить автора»

### 18.11.2026. Строка «Автор»: Написать / Поблагодарить
